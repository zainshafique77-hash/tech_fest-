# TechFest 2026 – University Tech Fest Website

A responsive three-page event website built with semantic HTML, CSS, and vanilla JavaScript.

## Features
- Accessible homepage with an event schedule and sponsor logos
- Responsive layout with light and dark themes
- Live countdown to the event start
- Events page with search, type and day filters, time sorting, and saved events
- Registration form with validation and a registration summary

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
